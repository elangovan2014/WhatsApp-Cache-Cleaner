WhatsApp Cache Cleaner 1.10

Author: ELANGOVAN

This version improves process identification. WebView2 is shared by many Windows applications, so its process name alone does not block cleanup.

  1. Scan storage: measures only the recognised WhatsApp cache folders.
  2. Check processes: checks WhatsApp.exe, WebView2 command/path markers, and parent-process relationships. Unrelated WebView2 processes do not block cleanup.
  3. Clean cache: available only after a successful scan and process check, followed by a separate confirmation.

If Windows hides both the command line and executable path for a WebView2 process, the add-on treats it as unidentified and keeps cleanup disabled. This is intentional for safety.

The add-on does not force-close processes, bypass permissions, take ownership, or elevate privileges. Cleanup results are measured after the attempt.

Service Worker CacheStorage may contain cached application resources or media. WhatsApp may need to download some content again after cleanup.

Protected: LocalState, session databases, IndexedDB, cookies, Local Storage, account/session data, and all unlisted folders.

Shortcut: NVDA+Shift+W. If not registered automatically, assign it in NVDA Input Gestures. If an earlier test build of WhatsApp Cache Cleaner is installed, remove it before installing this version.
